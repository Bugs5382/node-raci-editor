# node-raci-editor 🧩

> 🧭 Generic drop-in React rules editor, simulator and settings for RACI-style access rules, with a pure TypeScript decide() and shared test vectors.

## 📦 Install

```bash
npm install node-raci-editor
```

## 🚀 Usage

```ts
import { hello } from "node-raci-editor";

hello("world"); // "Hello, world!"
```

## 🛠 Develop

```bash
npm install
npm run build      # tsdown -> dist (esm + cjs + d.ts)
npm test           # vitest
npm run lint       # eslint + prettier
npm run docs       # typedoc -> docs
```
